# Windows

[All Skills](../README.md)

| Skill | Purpose |
| --- | --- |
| [windows-diagnostics](windows-diagnostics/SKILL.md) | Investigate Windows process, port, file-lock, service, scheduled-task, startup, crash, and event-log problems using scoped PowerShell queries and Sysinternals. Use for host diagnostics and evidence-backed repairs; Windows Sandbox, WSL, and application-specific workflows have their own procedures. |
| [windows-sandbox](windows-sandbox/SKILL.md) | Set up, configure, launch, automate, and troubleshoot Microsoft Windows Sandbox on Windows. Use for .wsb configuration files, disposable Windows app or installer tests, mapped folders, logon scripts, and the wsb CLI. Does not govern Codex execution sandbox permissions. |
| [winget-setup](winget-setup/SKILL.md) | Use WinGet to discover exact Windows packages, install or update requested tools, manage package pins, export/import tool setups, and bootstrap WinGet inside Windows Sandbox. Use for Windows package management and reproducible developer environments, with explicit package identity and scope. |
| [wsl-ops](wsl-ops/SKILL.md) | Diagnose and manage Windows Subsystem for Linux distributions, Windows/Linux paths, shell environments, networking, interoperability, configuration, and backups. Use for WSL-specific failures and requested distro maintenance; application bugs inside an otherwise healthy Linux environment do not require this skill. |
