# Lifecycle and Evidence

Consume the documented terminal event. Closing a stream releases the client connection; it does not prove that
provider work stopped, a background job was cancelled or no credits were used. Inspect retained resources and
use their explicit cancellation operation when appropriate. Never replay an uncertain mutation merely because
its response was lost. A request header called Idempotency-Key is not a universal deduplication guarantee.

Plans require approval of the exact current revision. Client function handlers run in the application and need
their own authorization. Unknown usage stays unknown; estimates, holds and settled charges are different.
Black Box integrity, recorded execution, persisted output, delivered files and semantic correctness are distinct.
Retain request/resource IDs, contract versions and actual errors without credentials or private prompt dumps.
