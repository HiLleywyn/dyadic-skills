# Dyadic Workflows

[Dyadic](../README.md) · [All Skills](../../README.md)

Repository-authored additions grounded in current Dyadic contracts. These are available instructions, not claims of installation into the official product catalog.

| Skill | When to use it |
| --- | --- |
| [Current Work Revision](dyadic-current-work/SKILL.md) | Revise accepted work in Dyadic while preserving the owner’s constraints, exact file versions and unresolved items. Use for a follow-up that changes an accepted delivery or needs a Patch against it. |
| [Artifact Handoff](dyadic-artifact-handoff/SKILL.md) | Trace a Dyadic deliverable from generated output to retained bytes, exact revisions and a usable attachment or UI reference. Use when a file, image or panel is reported complete but is missing, stale or cannot be opened. |
| [Receipt Reconciliation](dyadic-receipt-reconciliation/SKILL.md) | Explain interrupted or apparently contradictory Dyadic runs by separating execution state, recorded tool effects, accounting state and provider cost. Use for operation IDs, stopped runs, unknown charges or parent/child usage comparisons. |
| [Source Conflict Review](dyadic-source-conflicts/SKILL.md) | Resolve disagreements among supplied Dyadic documents, accepted briefs and later revisions without silently adding outside research. Use when dates, requirements, authority or quoted evidence conflict across the provided sources. |
